## 📌 快速开始

### 1. 选择后端环境

#### 方式A：使用线上服务器（当前配置 ✅）
无需启动本地服务，小程序直接连接到服务器：
- 地址：`http://42.193.230.145:8000`
- 配置文件：`miniprogram/config/config.js`

#### 方式B：使用本地开发服务器
在项目根目录运行：

```bash
# 方式1：使用本地开发脚本（推荐）
python start_local.py

# 方式2：使用生产脚本（需管理员权限）
python start_server.py
```

- `start_local.py`：启动在 **8000** 端口（开发推荐）
- `start_server.py`：启动在 **80** 端口（需管理员权限或改端口）

## 🔧 常见问题

### 问题1：登录失败，Console 显示 `request:fail`

**原因**：小程序配置的 API 地址错误

**解决**：
1. 确认 `app.js` 使用 `config-local`
2. 确认后端服务已启动（访问 http://localhost:8000/docs 验证）
3. 在微信开发者工具勾选"不校验合法域名"

### 问题2：端口占用

**错误**：`Address already in use`

**解决**：
```bash
# Windows 查找占用端口的进程
netstat -ano | findstr :8000

# 结束进程（将 PID 替换为实际值）
taskkill /PID <PID> /F
```

### 问题3：`ModuleNotFoundError: No module named 'cryptography'`

**原因**：缺少支付相关依赖

**解决**：
```bash
# 激活虚拟环境
D:\code\pet-memory-star\venv\Scripts\activate

# 安装支付依赖
pip install -r requirements_payment.txt
```

### 问题4：数据库不存在

**错误**：`no such table: users`

**解决**：
```bash
# 运行数据库迁移脚本
python migrate_memorial_tables.py

# 或检查数据库状态
python check_database.py
```

## 🚀 完整启动流程

1. **安装依赖**
   ```bash
   # 核心依赖
   pip install -r requirements.txt
   
   # 支付依赖（可选）
   pip install -r requirements_payment.txt
   ```

2. **启动后端**
   ```bash
   python start_local.py
   ```
   
   看到以下输出表示成功：
   ```
   INFO:     Uvicorn running on http://0.0.0.0:8000
   INFO:     Application startup complete.
   ```

3. **配置小程序**
   - 确认 `app.js` 使用 `config-local`
   - 微信开发者工具打开 `miniprogram` 目录
   - 勾选"不校验合法域名"

4. **启动小程序**
   - 点击"编译"按钮
   - 在模拟器中测试登录功能
